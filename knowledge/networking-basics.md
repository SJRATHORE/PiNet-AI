# Networking basics
DNS translates hostnames such as example.com into IP addresses. A DNS resolver helps clients find the destination IP address.
DHCP automatically provides devices with IP addresses, subnet masks, gateways and DNS settings on a network.
A Wi-Fi access point lets nearby devices join a wireless local network. A local network can work without any internet connection.
SSH lets you securely administer another computer across a network. Use strong authentication and do not expose it casually to the internet.
A VPN creates an encrypted tunnel between devices across another network.
TCP provides ordered, reliable byte streams. UDP sends datagrams without guaranteed delivery.
